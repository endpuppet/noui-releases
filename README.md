# noUI — releases & website

noUI is a living liquid eye that rides a rail around your screen. Tap it and four drones flow out — attach, notes, clipboard, prompts — with your own AI behind the eye.

- **Website:** https://endpuppet.github.io/noui-releases/
- **Downloads:** [Releases](https://github.com/endpuppet/noui-releases/releases)

This repository only holds published builds and the website. The source code is developed in a private repository; everything here is published automatically from it, so changes made directly in this repository are overwritten.
